几步就能用

  1. Mac：打开 DMG，把 Codex Ledger 拖进 Applications。Windows：运行安装包，安装到当前用户目录。
  2. 打开应用，点击菜单栏或系统托盘图标。如有需要，在设置中选择 Codex 数据目录。
  3. 创建目标，归入相关对话，查看累计金额。在分享菜单生成图片。

这些数字代表什么

金额为按标准 API 单价计算的美元估算，不代表订阅扣款或实际账单。未知模型保留为未计价用量，只覆盖本机可读取的日志。
