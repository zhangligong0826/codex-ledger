# Beta.4 目标成本改版实施记录

目标版本：1.2.0-beta.4（build 16）。验收完成前不发布或更新安装入口。

## 阶段与验证门槛

1. 数据与兼容性：v2 规则、稳定开始时间、分范围完整性、完成历史、原始 v1 备份、精确 Decimal 双向备份；回归去重与子代理，新增场景测试。
2. 操作流程：在目标内选择工作、预览移出目标、默认固定历史、明确完成和分享、撤销、返回恢复上下文、独立菜单栏日期。
3. 界面与分享：紧凑金额层级、受窗口约束的两栏、图表交互和键盘、冻结范围与时间、刷新可分享、每项导出分别判断可用性。
4. 安装与发布：三种 Mac CI、Windows x64 运行与安装测试、ARM64 构建、确切六份包与 SHA-256、本机升级、预发布、下载页、Homebrew。

## 兼容边界

- v1 账本保持原文件/偏好，v2 使用独立存储。迁移失败停止写入。
- v1 bindings 明确作为旧版持续归属保留，不能默认冻结它们。
- 缺少原始成员信息的旧完成记录标记为 legacy，金额和价格日期保留。
- 不同版本导出的备份包含版本；v2 可导入 v1，旧应用不承诺识别 v2。
- 本机日志只读；公开测试及 UI 预览使用合成记录。

## 交付证据

最终中文报告会逐项列出自动测试、实际 Mac 操作、固定语料性能、Windows CI，以及尚无物理设备验收的项目。不能将构建成功称为 ARM64 实机验证。
